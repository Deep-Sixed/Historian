# Tailscale vs Tailescale

### Assistant

**Tailscale** is spelled:

```text
Tailscale
```

Not:

```text
tailescale
```

For Linux commands:

```bash
tailscale status
tailscale ip -4
sudo tailscale up
```

For your VM/LAN topic: Tailscale gives the VM a **separate Tailscale IP**, usually `100.x.x.x`, but it does **not** assign a normal LAN IP like `10.0.0.125`. That `10.0.0.125` address comes from either:

```text
Your router/DHCP server
```

or

```text
A static IP manually set inside the VM
```

VMware Bridged Mode + Static IP inside the VM
