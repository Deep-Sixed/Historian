# Secure Boot NVIDIA DKMS

### Assistant

The screenshots show a very specific and common Secure Boot failure path on Debian with NVIDIA DKMS.

From the text shown:

- NVIDIA driver `550.163.01` is installed.
- DKMS successfully built the kernel module.
- Secure Boot is enabled.
- Loading the module fails with:
  ```
  Key was rejected by service
  ```
- Kernel reports:
  ```
  Loading of module with unavailable key is rejected
  ```

That means:

1. The NVIDIA driver itself is probably fine.
2. The DKMS build itself is probably fine.
3. The kernel is refusing to load the module because Secure Boot does not trust the signing key.

The proposed fix in the screenshot is also the normal fix:

- Queue the DKMS Machine Owner Key (MOK) for enrollment.
- Reboot.
- Use the blue MOK Manager screen.
- Enroll the key.
- Reboot again.

If the MOK enrollment succeeds, then after reboot:

```bash
nvidia-smi
```

should return GPU information instead of:

```text
NVIDIA-SMI has failed because it couldn't communicate with the NVIDIA driver
```

The important thing to verify after reboot is not just `nvidia-smi` but also:

```bash
mokutil --list-enrolled | grep -i dkms
```

and

```bash
modinfo nvidia | grep signer
```

You should see a signer associated with the enrolled key.

For your Lenovo P70 recovery effort, this is actually a good sign. The failure shown is not:

- a bad GPU
- a broken kernel
- a failed DKMS compile
- a PCIe detection problem

It's a Secure Boot trust-chain issue. Those are usually resolved once the MOK is properly enrolled.

One caveat: sometimes the blue MOK screen never appears even though a key was queued. If that happens, check:

```bash
mokutil --sb-state
mokutil --list-new
```

If `--list-new` is empty, the enrollment request didn't get staged correctly and must be re-imported.

Based on the screenshots alone, the next step is exactly what Codex described: reboot and complete the MOK enrollment. After that, the first thing I'd want to see is the output of:

```bash
nvidia-smi
```

and

```bash
lspci -nnk | grep -EA4 'VGA|3D|Display|NVIDIA'
```

Those two commands will tell us immediately whether the P70's NVIDIA GPU is actually bound to the `nvidia` driver.

### Assistant

Press **Enter** on **OK**.

Then choose **Continue boot**.

Once Debian boots, re-stage it with a new known password:

```bash
sudo mokutil --delete /var/lib/dkms/mok.pub 2>/dev/null || true
sudo mokutil --import /var/lib/dkms/mok.pub
```

Set a simple temporary password you can type reliably on that firmware screen, for example all lowercase letters/numbers only.

Then reboot and enroll again.
