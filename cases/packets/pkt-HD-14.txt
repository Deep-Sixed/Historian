### Key takeaways from Mintlify's Claude Code documentation workflow

#### 1. Claude Code is treated as a documentation teammate, not an autocomplete tool
Mintlify's technical writing team uses Claude Code to:

- Read the codebase
- Analyze recent Git changes
- Search existing documentation
- Draft new documentation
- Review documentation for consistency
- Update documentation when features change

The workflow is built around repository-wide context rather than isolated prompts. citeturn0search1turn0search0

#### 2. The critical artifact is `CLAUDE.md`
Instead of repeatedly prompting Claude, they maintain project-specific instructions in a `CLAUDE.md` file that acts as persistent guidance.

Typical contents include:

- Writing standards
- Documentation structure
- Voice and style rules
- Product terminology
- Review checklists
- Team workflows

This effectively becomes an operational playbook for the agent. citeturn0search0turn0search1

#### 3. Documentation is increasingly optimized for agents
Mintlify's broader strategy is that docs are no longer just for humans.

They automatically expose:

- Markdown versions of pages
- `llms.txt`
- `llms-full.txt`
- MCP servers
- AI-readable content structures

The goal is to make documentation directly consumable by Claude Code, Cursor, ChatGPT, and other coding agents. citeturn0search17turn0search6turn0search2

#### 4. MCP is becoming a major distribution mechanism
Mintlify generates hosted MCP servers from documentation.

That means an agent can:

- Search docs
- Retrieve full pages
- Navigate documentation structure
- Use documentation as live context during task execution

without scraping websites or relying on training data. citeturn0search6

#### 5. Structured docs materially improve agent performance
Mintlify reported experiments comparing:

- Minimal docs
- Human-written docs
- Mintlify + MCP connected docs

The documented results showed:

- Higher answer precision
- Better discoverability
- Fewer tokens consumed
- Faster task completion

when agents had access to structured documentation and MCP. citeturn0search9
